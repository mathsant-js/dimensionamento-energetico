# Descrição das Funcionalidades

Documento para descrever as funcionalidades do projeto

## Funcionalidades do Usuário

Usuário informa seu nome e tipo de residência;

Usuário informa os eletrodomésticos de seu imóvel;

Usuário informa tempo médio diário de utilização

## Funcionalidades do Sistema

Sistema apresenta base de dados com nome, categoria e potência de equipamentos elétricos;

Sistema calcula consumo mensal de cada equipamento e do total do imóvel
